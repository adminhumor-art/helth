# Семейный сайт «Сладкая»

Без серверных настроек сайт работает как явно помеченный демонстрационный экран
с синтетическими данными. При заданных `SLADKAYA_BACKEND_ORIGIN` и
`SLADKAYA_PATIENT_ID` он переключается в семейный режим: предлагает защищённый
вход, получает snapshot и историю только через server-side proxy, показывает
большое свежее значение и позволяет подтвердить открытую тревогу.

При недоступности, просрочке или несогласованности живых данных сайт скрывает
число и никогда не подставляет вместо него демо. Session и CSRF хранятся в
`HttpOnly` cookie; исходный семейный код используется только для одноразового
server-side обмена и не сохраняется браузером.

Текущий deploy закрыт для владельца проекта:
`https://sladkaya-family-demo.rinatvfx.chatgpt.site`.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run build
npm test
npm run lint
```
