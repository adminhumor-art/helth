# Семейный сайт «Сладкая»

Сейчас это визуально проверяемый демонстрационный экран только с синтетическими
данными. Он показывает главный продуктовый порядок: большое текущее значение,
график без ложных линий через пропуски, тревога и состояние устройств.

Демо не подключается к датчику, не содержит реальных людей и не выдаёт
медицинских рекомендаций. Доступ к реальным семейным данным будет добавлен
только вместе с серверной авторизацией и проверенным backend-контуром.

Текущий deploy закрыт для владельца проекта:
`https://sladkaya-family-demo.rinatvfx.chatgpt.site`.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run build
npm test
npm run lint
```
