# Граница исходного кода

«Сладкая» создаётся как частное семейное решение.

- В продукт не переносится исходный код сторонних приложений мониторинга.
- Прямой драйвер и адаптер нативного ядра пишутся внутри проекта через небольшой
  собственный интерфейс.
- Нативные библиотеки SiBionics сохраняются отдельно от бизнес-логики с
  зафиксированными контрольными суммами.
- Исследовательский upstream используется как эталон поведения и не становится
  автоматически частью продукта.
- Если позже будет принято решение переносить GPL-код, авторские и лицензионные
  уведомления сохраняются; такое изменение требует отдельного решения владельца.
- Право публично передавать нативные библиотеки производителя не считается
  доказанным только фактом их наличия в официальном APK. Перед публикацией APK
  на сайте этот вопрос проверяется отдельно.
- Любое значение допускается к экрану и тревогам только после автоматической
  проверки целостности ядра, тестов на записанных пакетах и физического сравнения
  с официальным приложением.
