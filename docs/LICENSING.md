# Граница исходного кода

«Сладкая» создаётся как частное семейное решение.

- В продукт не переносится исходный код сторонних приложений мониторинга.
- Прямой драйвер и адаптер нативного ядра пишутся внутри проекта через небольшой
  собственный интерфейс.
- Нативные библиотеки SiBionics сохраняются отдельно от бизнес-логики с
  зафиксированными контрольными суммами.
- Исследовательский upstream используется как эталон поведения и не становится
  автоматически частью продукта.
- Если позже будет принято решение переносить GPL-код, авторские и лицензионные
  уведомления сохраняются; такое изменение требует отдельного решения владельца.
- Право публично передавать нативные библиотеки производителя не считается
  доказанным только фактом их наличия в официальном APK. Перед публикацией APK
  на сайте этот вопрос проверяется отдельно.
- Любое значение допускается к экрану и тревогам только после автоматической
  проверки целостности ядра, тестов на записанных пакетах и физического сравнения
  с официальным приложением.

## Лицензия Android-эмулятора — отдельный технический пункт

`android-sdk-arm-dbt-license` относится только к загрузке дополнительного ARM
system image для локального Android-эмулятора. Это не лицензия «Сладкой», не
лицензия датчика, не ключ приложения и не условие установки на реальный Samsung.

Пока реального телефона нет, непринятие этой лицензии блокирует только один
дополнительный локальный runtime-прогон. JVM-тесты, сборка APK, compile/assemble
instrumentation-тестов и вся остальная разработка продолжаются. Когда появится
Samsung, подготовленные ARM-smoke выполняются на нём без этой emulator-лицензии.

## Подпись APK — не лицензия

Постоянный release-keystore — криптографическая идентичность Android-приложения.
Он нужен, чтобы следующая версия устанавливалась поверх первой без удаления
данных и checkpoint активного датчика. Keystore создаётся один раз, хранится вне
Git и обязательно имеет независимую резервную копию. Сборка установочного release
в проекте блокируется, пока не заданы:

- `SLADKAYA_RELEASE_STORE_FILE`;
- `SLADKAYA_RELEASE_STORE_PASSWORD`;
- `SLADKAYA_RELEASE_KEY_ALIAS`;
- `SLADKAYA_RELEASE_KEY_PASSWORD`.

Пароли и сам keystore не записываются в репозиторий, документацию или логи.
